# NEXTRACK — 성복동 분동 청원 #3972 연계 확장판

이 버전은 기존 실제 청원 CSV **10건**에 청원 **#3972 1건을 추가**해 **11건**을 표시합니다.
기존 관련자료 연결 레코드 **18건**에 원본 HWPX 공고문 **1건**을 연결하여 **19건**입니다.
원본 CSV의 기존 10행 및 연결 기록 18행은 보존했습니다. `dashboard.csv`는 원본을 유지했으므로 과거 표본 기준 요약 데이터이며, 라이브 화면의 청원 수는 현재 `petitions.csv`에서 계산합니다.

## 실행
```bash
npm install
npm run dev
```

## 사용법
1. 대시보드 > `성복동 분동 청원 #3972` 카드 클릭 또는 청원 목록에서 `3972` 검색
2. 상세 화면 하단 `성복동 분동 · 청원–행정자료 연결 추적`에서 날짜별 타임라인 확인
3. `공고문 HWPX 받기`를 눌러 첨부된 공식 공고문 원본 열기
4. `후속자료 실증`에서도 해당 조사 사례를 확인 가능

## 검증 한계
- 공식 청원 화면 캡처: 제목, 202명, 2026-09-21~10-21, 답변완료 표시만 확인.
- 공식 답변 **본문 및 답변 게시일은 미확보**. 답변에서 '추가 주민설명회'를 약속했다는 내용은 사용자가 제공한 조사표에서 나온 것이며 공식 답변 본문 대조 전입니다.
- 공식 공고 제2026-3182호(2026-11-17): 2026-12-04 10:00 2차 주민설명회 개최 예정. 실제 개최 여부 및 분동 확정 여부 미확인.
- 공고문에 청원 ID #3972가 명시되지 않아 **동일 현안 관련자료이지 해당 청원의 직접적인 후속 조치로 검증된 것은 아님**.
- 공식 공고문의 온라인 게시 URL은 확보되지 않았으며 원본 HWPX 파일을 `public/documents/`에 포함.
- 실제 개별 청원 좌표는 미검증이므로 지도 마커를 만들지 않음.

## 추가 기능: 공식 고시·공고 검색 및 자동 연관자료 추천

- 상단 **고시·공고 검색**에서 확보된 공식 공고문을 검색할 수 있습니다.
- 공식 원문은 **용인시 전자민원 고시·공고 목록** 및 첨부한 HWPX 자료로 연결됩니다.
- 청원 상세에서는 공고문에 대한 **설명 가능한 규칙 기반 유사도 추천**과 근거를 확인합니다.
- 추천 검토 상태를 변경하면 로컬 브라우저에만 기록됩니다(실제 관리자인증 아님).
- 확인된 공고: `용인시 공고 제2026-3182호`, 공식 목록 관리번호 10305.
- 해당 공고만을 바로 여는 개별 상세 URL은 검증되지 않아 만들어 넣지 않았습니다.
- 용인시 사이트 전체를 실시간 검색하거나 자동 수집하는 기능은 아닙니다. 확보된 공식 원문 데이터베이스 범위 내 검색이며 전체 목록으로 연결됩니다.

확인할 명령: `npm install && npm run check && npm test && npm run build && npm run dev`
